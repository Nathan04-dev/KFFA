# 🥊 KnockbackFFA

Ein actionreicher Knockback-FFA-Spielmodus entwickelt von Nathanael Mabombo. Stelle dich spannenden Kämpfen gegen andere Spieler, stoße deine Gegner von der Plattform und kämpfe um den ersten Platz auf dem Leaderboard.

## ✨ Features

- **Konfigurierbare Spielmechaniken** – Individuelle Einstellungen und Anpassungsmöglichkeiten für den Spielmodus
- **SQL-Datenbank** – Speicherung und Verwaltung von Spielerstatistiken
- **Integriertes Kill-System** – Erfassung und Verwaltung von Kills
- **Respawn-System** – Automatischer Respawn nach dem Ausscheiden
- **Leaderboards** – Übersicht der besten Spieler und ihrer Statistiken
- **Verschiedene Kits** – Unterschiedliche Ausrüstungen für abwechslungsreiche Kämpfe

## 🛠️ Tech Stack

- **Programmiert mit Java**
- **API: Spigot API**
- **Datenbank: SQL**
  **IDE: Eclipse**
